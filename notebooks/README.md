# Notebooks

Use notebooks for dataset preparation and inspection.

1. `01_prepare_wikiart_subset.ipynb`
   Select a balanced 300-500 image subset from WikiArt and generate `critique_labels_v1.csv`.

2. `02_label_review.ipynb`
   Display images with current labels for manual review.

3. `03_dataset_stats.ipynb`
   Check label counts, missing values, and train/validation/test split balance.

Run from the repository root or from inside `notebooks/`.
